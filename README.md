# Closure Call

Weather-driven facility closure decisions and employee notification.
Built at Hack Midwest 2026 (USDA, AWS Strands and Akamai Cloud challenges).

## Setup

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    copy .env.example .env    (then paste the team key into .env)
    python scripts/check_endpoint.py
